# Coopanion v0.2.26

**The WebFetch World has its own settings page**

## Added

- **WebFetch under World overview in the advanced mode**: two lamps (pages / pictures), a badge per key (page / Pixabay / Pexels), and a Quick setup panel. Set or clear a key on the page; a key is only ever shown masked (first six and last four characters), and one button tests picture search.
- **One settings group**: Fetch API base URL, page receipt limit, picture size limit, pictures per search, request timeout; every change applies at once, no restart.
- A key saved on the page goes into the same deployment `.env` (`data/home/companion/.env`), exactly as editing the file would.

## Notes

- The page's text follows the vendored Worlds: Chinese and English, with other languages reading English.
- The test button sends one real search that takes a single result, which spends one API call.
