# Coopanion v0.2.31

**Pictures in a page come back directly; pictures Pixabay lacks come from Bing**

## Added

- **Pictures listed with a page read**: the receipt ends with the picture addresses the page declares (og:image, ordinary images, lazy-loading attributes and srcset included); hand one to `web_fetch_image` and the picture comes back, without driving the browser.
- **Bing picture fallback**: when Pixabay has no key, refuses, or finds nothing, Bing's keyless image search answers instead, and the receipt names the source.

## Changed

- **Pexels removed**: it stopped issuing keys, so its code, settings row, tests and docs are gone and Pixabay carries the picture library.
- Three new settings: pictures listed per page (12), page HTML limit (2 MB) and the Bing fallback (on by default); all apply at once.

## Notes

- The picture list is best effort: pages that block direct reads, challenge bots or need a login (Wikipedia, Zhihu, Xiaohongshu) yield no addresses, and those still need the browser.
- A picture search spends one Pixabay request first; the Bing fallback only runs when that has no answer.
