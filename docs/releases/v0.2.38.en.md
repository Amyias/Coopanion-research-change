# Coopanion v0.2.38

**Upstream 0.2.22 and 0.2.23 merged: Coo hears your voice, a native Windows on Arm build, separate bubble stay times, Gemini 4**

## Brought in from upstream (23 commits)

- **Coo hears your actual voice**: on multimodal Gemini / Doubao endpoints each batch of speech is sent with its recording beside the transcript, so you can sing to Coo or have your pronunciation corrected; the Voice Input page turns the recording and the transcript on or off separately, and batches over the recording limit send text only.
- **A native Windows on Arm build**: arm64 installer and portable zip, no x64 emulation on Arm PCs; an Arm PC already running the x64 build keeps updating the x64 build.
- **Separate stay times for say and input bubbles**: auto or a fixed 1–60 seconds each, on the Habits page.
- **Gemini 4**: the default model is `gemini-4-hydrogen`, with `gemini-4-argon`, `gemini-4-carbon` and `gemini-4-neon` recommended; all four are multimodal and carry built-in prices.
- **Settings window**: a "back to the bottom" button after scrolling up in the chat page, an ⓘ beside a World's title opening the extension's details, and Esc closing only the topmost of two stacked dialogs.
- Fixes: an old PDF pushing out a new screenshot, the top hat crown not being pettable, narrow figures not reaching the screen edge, right-click menu and hover buttons laid out differently, status lamps flickering when the rail hides Worlds, the opening guide's transition line lingering.
- Cortico submodule v0.2.17: a large usage ledger no longer exhausts memory when today's cost is opened, and a half-written tool call in the history no longer makes a whole request rejected; the attachment fallback is now `AttachmentFallback`.

## What this fork keeps

- The Windows on Arm build is merged whole (installer, portable zip, `latest-arm64.yml`, pack checks, NSIS text); the release now carries about 16 assets instead of 12.
- The READMEs take upstream's Arm download instructions while keeping this fork's repository links, badges and not-official notice; DEVELOPMENT keeps the "the release is created by Actions" and Node updater notes.
- Bubble picture carousel and lightbox, `/say-image`, page picture lists, the Bing fallback, the Node updater and NOTICE all survive.
- The version number follows our own sequence.
