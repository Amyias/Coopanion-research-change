# Coopanion v0.2.19

**The updater writes a log again: after the move to Node it ran, but recorded nothing**

## Fixed

- **The updater's logger was wired one level off**: after v0.2.18 moved the check and the download to Node's https, the callback returned a function instead of writing, so a failing check left no trace. Each check, the release found, and a failed check or download now go to `updater.log`.
- One line at startup says which transport is in use, which repository, and the current version.

## Notes

- Web search, page reading and computer use are unchanged.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.19.exe`
- `latest.yml`: the version file the updater reads; no need to download it.
