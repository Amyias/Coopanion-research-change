# Coopanion v0.2.32

**Upstream merged: the settings window's messages are unified, and the microphone has a device picker**

## Brought in from upstream

- **Settings window**: consistent errors and status hints across the extension market, World removal/restart-pending, prompts, providers, config, storage, usage, home, dress-up, outfits and computer-use pages, plus a batch of layout and interaction fixes.
- **Pet voice**: pick a specific microphone, falling back to the system default when it is gone; microphone AGC is off; audio at the start is kept when the talk and type keys are shared; Ctrl and Alt inside a chord no longer count as repeated presses.
- **Picture receipts**: a batch delivered right after a tool receipt still carries the receipt's pictures on the next request.
- **README rewrite**: both READMEs follow v0.2.17 with new screenshots.

## On our side

- Every fork addition survives the merge: page picture lists, the Bing picture fallback, bubble pictures and their lightbox, the Node updater, the not-official notice and NOTICE.
- **The one-line installer now points here**: it used to ask upstream for the latest release and install official Coopanion.
- The READMEs keep upstream's new structure, with this repository's badges, the not-official notice and the web-search feature restored; every repository link names this fork.

## Notes

- Development moves to vitest 4 (nothing changes for users); Windows updates work as before, macOS and the portable build are downloaded by hand.
