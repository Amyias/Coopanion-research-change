# Coopanion v0.2.40

**合并官方 0.2.24 与 0.2.25:Coo 可以变淡、鼠标穿透时按住键能点到它、气泡折行等长、按 World 看用量;交接修复**

## 合并的官方改动(36 个提交)

- **Coo 可以变淡**:「习惯 → 显示 → 透明度」0–95%,也可以把「透明度」加进悬停按钮在头顶拖滑条;只淡形象,气泡/按钮/菜单不变;Windows「全屏时」多一档「变淡」(默认 40%)。
- **鼠标穿透时按住键点到 Coo**:新增「暂停穿透键」(默认右 Ctrl),穿透开着时按住它照常接收点击;悬停按钮可加「鼠标穿透」「电脑操作」开关。
- **动态效果分档**:低 / 中 / 高 / 跟随系统(默认)。
- **气泡**:折行收窄到各行等长、关闭按钮移到气泡外、输入框文字占满整行、自动档输入气泡在回复写完 0.5 秒后先淡出、尾巴线宽对齐;习惯页新增「气泡」一节,带可播放的示例。
- **只投递录音时不等识别**,识别服务可单独停用并持久化。
- **World 环境提示词页工具栏**;未保存离开改用应用内弹窗;**用量页「按 World」**溯源。
- 修复:改屏幕缩放后悬空、峰谷计价实例重启后被改成 coo(删掉 0.1.2 端点迁移)、重启后配色被改、超字数被截断、Core 同端口重启后设置窗口不刷新、拖过两屏交界闪帧、引导台词被鼠标停住、左右不对称形象贴不到边等。
- **0.2.25**:修复 0.2.24 上「第一次交接后不再交接」;交接压不下时只再试一次并在 `logs\core.log` 写明可调项;进程崩溃留下 `.dmp`;交接后首次请求的上下文估算含工具清单;子模块 Cortico v0.2.19。
