# Coopanion v0.2.27

**修好 WebFetch 面板的空白页**

## 修复

- 0.2.26 里 WebFetch 的「快速配置」页签只显示"缺少面板构建产物":面板声明了服务端契约,却没带浏览器端 bundle。现在补上 `core/web-fetch/webui/client.ts`,由 `scripts/stage.ts` 构建成 `build/panels/web-fetch/webui.js`,并在装配里注册为 `world:web-fetch` 的页面资源。
- 页面现在列出三个密钥(网页 / Pixabay / Pexels)的配置状态,可以粘贴保存、清除,以及一键测试搜图。

## 说明

- 面板文案是中文与英文,和 Cortico 自带的 World 一致。
