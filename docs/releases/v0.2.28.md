# Coopanion v0.2.28

**合并官方新提交:托盘多了「鼠标穿透」,桌宠不再被 App Store 压到后面**

## 从官方并入

- **鼠标穿透**:托盘菜单新增开关,打开后点击都穿过 Coo,不再挡鼠标;状态记在配置里,重启保持。
- **桌宠与 App Store**:App Store 在前台时桌宠不再退到其他窗口后面;在商店里购买可用触控 ID 确认。
- **让位与阻塞输入**:修正"给窗口让位"的行为,并如实上报被阻塞的输入。
- **控制台**:共享下拉框与悬浮提示、扩展图片画廊、市场与 World 页的多处修复;「我的 World」行可拖动排序(拖动时滚动、头像居中);供应商卡片可重排、重设样式、删除有确认;用量页控件稳定、货币写成符号;提示词预览可折叠;单按钮提示对话框;市场筛选恢复后回到原位置。
- 11 个语言补齐新开关的文案。

## 我们这边

- **合规声明**:新增 `NOTICE`(上游仓库与提交、修改清单、许可证归属),两个 README 顶部写明这是**个人修改版、非官方**。
- **构建者信息**:安装包的发布者改为本仓库(作者 Amyias),不再显示上游。
