# Coopanion v0.2.38

**合并官方 0.2.22 与 0.2.23:Coo 能听到你的原声、Windows on Arm 原生版、气泡停留时间可分别调、Gemini 4**

## 合并的官方改动(23 个提交)

- **Coo 能听到你的原声**:用 Gemini / 豆包多模态端点时,每批语音的录音会和转写文字一起发给模型,可以唱歌给它听或让它纠正口语;「语音输入」页可分别关「投递录音」「投递转写」,超过「录音上限」时只发文字。
- **Windows on Arm 原生版**:新增 arm64 安装版与便携版,Arm 电脑不用再经 x64 仿真;已装 x64 版的 Arm 电脑照常自动更新到 x64 版。
- **台词气泡与输入气泡分别设停留时间**:习惯页各可选「自动」或固定 1–60 秒。
- **Gemini 4**:默认模型改为 `gemini-4-hydrogen`,推荐型号加入 `gemini-4-argon`、`gemini-4-carbon`、`gemini-4-neon`,四个都按多模态处理并有内置价目。
- **设置窗口**:对话页往上翻后出现「↓ 回到底部」;World 设置页标题旁的 ⓘ 直接打开扩展详情;两层弹窗按 Esc 只关最上层。
- 修复:旧 PDF 挤掉新截图、礼帽帽顶摸不到、瘦高形象走不到屏幕边、右键菜单与悬停按钮排法不一致、设置窗口左栏状态灯闪动、开局引导过渡台词停留过久。
- 子模块 Cortico v0.2.17:用量账本大时查今日花费不再吃满内存退出、历史里写到一半的工具调用不再让整条请求被拒;附件回落改名 `AttachmentFallback`。
