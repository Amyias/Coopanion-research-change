# Coopanion v0.2.30

**合并官方 0.2.17:音效有了音量,语音喊停能打断电脑操作**

## 从官方并入

- **音效音量**:习惯页「音效」多了音量滑条,调的包括说话声。
- **语音喊停**:按说话键说的话会打断 Coo 正在进行的电脑操作和正在生成的回复;始终收音时不打断。
- **说话键与打字键相同时**:按住超过 0.3 秒才开始收音,双击打字在第二下松开时打开打字框,不再先闪一下。
- **设置窗口**:侧栏的 World 跟随「我的 World」的拖动顺序;「我的 World」点头像也能打开扩展信息、头像也能拖动整行;供应商卡片可拖动排序、删除前有确认。
- **修复**:macOS 上桌宠挡住 App Store 触控 ID;电脑操作时把早先的指针位移误当成刚发生;会话文件被杀毒或同步软件短暂占用时应用退出(现在重试约 3 秒);收尾提醒设得不小于单次唤醒上限时一次也不出现。
- **子模块升到 Cortico v0.2.12**:WebUI 换成设置窗口当前版本,World 启停错误按界面语言显示,扩展 id 被占用时写 WARN。

## 说明

- 我们的版本号继续自己的序列;官方 0.2.17 的说明不覆盖我们已发的同号版本记录。
- Windows 自动更新照旧,macOS 与便携版手动下载。
