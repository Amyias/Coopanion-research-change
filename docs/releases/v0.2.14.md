# Coopanion v0.2.14

**Coo 可以直接上网搜索，用带来源的结果回答，不必再操控电脑;更新改由本仓库提供**

## 新功能

- **联网搜索**:Coo 多了一个 `web_search` 工具。遇到不确定或刚发生的事，它自己上网查，拿回带标题、链接和摘要的几条结果，据此回答。搜索不经过电脑操作，也不用打开浏览器。
- **搜索服务**:Brave Search 或 DeepSeek Search。密钥在高级模式「World 总览」→ WebSearch →「快速配置」填写，也可以放在 `BRAVE_API_KEY` 或 `DEEPSEEK_SEARCH_API_KEY` 环境变量里。没有密钥时工具照旧在，调用会拿到「未配置」的回执，Coo 不会编造结果。

## 改动

- **更新来源**:自动更新、标题栏的版本提示和 GitHub 链接都改指本仓库(Amyias/Coopanion-research-change)的 Release，不再跟随上游。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.14.exe`
- `latest.yml`:自动更新读的版本信息，不用下载。

这个版本由本仓库自行构建，只有 Windows x64 安装版;安装包没有数字签名，首次运行时 Windows 可能拦截。简体中文和英文以外的译文沿用上游。
