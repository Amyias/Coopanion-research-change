# Coopanion v0.2.20

**Updates install again: the previous version handed the setup a flag that makes it abort**

## Fixed

- **Downloaded but never installed**: v0.2.19 ran the setup with `--updated /S --force-run`, and this setup aborts with exit 2 when `--updated` is present (by hand as well). It now uses `/S --force-run`: silent, into the directory the program runs from, and the app starts again afterwards.
- After this version, an update walks the whole path by itself: check → download → verify → install on quit → restart.

## Notes

- v0.2.19 cannot install its own update, so this one has to be installed by hand once.
- Web search, page reading and computer use are unchanged.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.20.exe`
- `latest.yml`: the version file the updater reads; no need to download it.
