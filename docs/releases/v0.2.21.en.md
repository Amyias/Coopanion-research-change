# Coopanion v0.2.21

**The update check no longer calls github.com first: one API request in 0.1–0.9 s, and a failure says why**

## Fixed

- **The check fetched latest.yml first**: that request goes to `github.com`, which times out on some machines and left the check stalled or silent. The version, the file size and its sha256 now come from the release answer, so a check is one API request and `github.com` is not touched until a download is due; an older answer without a digest still falls back to `latest.yml`.
- **Every request has a hard deadline**, and a failed check or download writes a line to `updater.log`.
- The install keeps the `/S --force-run` arguments fixed in the previous version.

## Notes

- This version still has to be installed by hand once; after that an update walks the whole path: check → download → verify → install on quit → restart.
- Web search, page reading and computer use are unchanged.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.21.exe`
- `latest.yml`: the version file the updater reads; no need to download it.
