# Coopanion v0.2.24

**搜图改用 Pixabay:一个 key 就能用,还会告诉你图是谁拍的**

## 变更

- **默认走 Pixabay**:Pexels 已停止签发 key，所以 Pixabay 成了主要来源（key 在 https://pixabay.com/api/docs/ 登录后复制，写进 `data/home/companion/.env` 的 `PIXABAY_API_KEY`）。两个 key 都在时先问 Pexels，它失败或没结果再问 Pixabay，不会互相挡着。
- **回执带上作者和图源**:每条结果是 `标题 — 直链 (by 作者 · Pixabay)`，需要署名时直接能用。
- **中文查询用中文标签搜**:查询里有汉字时带 `lang=zh`，搜“柯基”比搜“corgi”更准。
- **默认安全搜索**:Pixabay 请求始终带 `safesearch=true`。

## 修复

- 手工检查脚本 `scripts/check-image-search.ts` 结尾的 `process.exit()` 会让 Node 24 触发 libuv 断言崩溃；改成设置退出码，运行正常返回。

## 说明

- 抓网页的 6,000 字符上限、气泡里显示缩略图这些都没动。
