# Coopanion v0.2.28

**Upstream merged: the tray gains “click-through”, and the pet stays above the App Store**

## Brought in from upstream

- **Click-through**: a new tray switch; while it is on, clicks pass through Coo. The state is saved and survives a restart.
- **Pet and the App Store**: the pet no longer falls behind other windows while the App Store is in front, and purchases there can be confirmed with Touch ID.
- **Yielding and blocked input**: the pet's yielding behaviour is corrected, and blocked input is reported as such.
- **Console**: shared dropdowns and hover hints, an extension picture gallery, several market and World fixes; My World rows drag with a live gap and scroll while dragging; provider cards reorder, restyle and ask before deleting; the usage page's controls are steady and currencies show as symbols; the prompt preview folds; a one-button notice dialog; a dropped market filter returns to where it was.
- Eleven languages gained the new switch's text.

## On our side

- **Notices**: a new `NOTICE` lists the upstream repository and commit, the modifications and the license, and both READMEs say above the fold that this is a **personal modified version, not an official release**.
- **Publisher**: builds name this repository's author (Amyias) rather than upstream.

## Notes

- Windows updates work as before (Node check and download); macOS and the portable build are downloaded by hand.
- Upstream has not released these commits yet, so the version number follows our own sequence.
