# Coopanion v0.2.15

**Coo can read a page you hand it: beside search, `web_fetch` returns a page's title and Markdown body**

## New

- **Read a page**: given a link, or when a search result needs its full text, Coo calls `web_fetch` and gets the title plus the Markdown body. A long page is cut at 12000 characters and the receipt says how many characters it had.
- **No new setting**: it uses the DeepSeek key already configured for search. A refusal carries the service's own reason (403 its policy, 404 no usable content, 402 out of credit).

## Notes

- Windows x64 installer only; automatic updates read this repository's releases.
- The installer is not code signed, so Windows may warn on the first manual run.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.15.exe`
- `latest.yml`: the version file the updater reads; no need to download it.
