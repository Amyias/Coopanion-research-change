# Coopanion v0.2.14

**Coo can search the web itself and answer from results with their sources, without using the computer; updates now come from this repository**

## New

- **Web search**: Coo has a `web_search` tool. For anything new or uncertain it searches the internet and gets back a few results with titles, links and snippets, then answers from them. No computer use, no browser window.
- **Search services**: Brave Search or DeepSeek Search. The key goes on the WebSearch page under World overview in the advanced mode, or in `BRAVE_API_KEY` / `DEEPSEEK_SEARCH_API_KEY`. Without a key the tool stays and returns "not configured", so Coo does not invent results.

## Changed

- **Update source**: automatic updates, the version hint in the title bar and the GitHub link now point at this repository's releases (Amyias/Coopanion-research-change), not upstream.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.14.exe`
- `latest.yml`: the version file the updater reads; no need to download it.

This build is made from this repository and ships the Windows x64 installer only; it is not code signed, so Windows may warn on first run. Translations other than Simplified Chinese and English come from upstream.
