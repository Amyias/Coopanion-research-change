# Coopanion v0.2.26

**WebFetch 有自己的设置页了**

## 新增

- **高级模式「World 总览」里的 WebFetch**:两个状态灯(读网页 / 搜图)、三个密钥徽章(网页 / Pixabay / Pexels)、一个「快速配置」页签。粘贴或清除密钥都在页面里做,密钥只显示打码后的样子(前 6 位与后 4 位),还可以一键测试搜图。
- **一个设置组**:Fetch API 地址、网页回执上限、图片大小上限、搜图返回条数、请求超时;全部即时生效,不用重启。
- 页面里写下的密钥存进同一个部署 `.env`(`data/home/companion/.env`),和手写文件等价。

## 说明

- 面板文案与 Cortico 自带的 World 一致:中文、英文各一份,其他语言读英文。
- 测试按钮会真的发一次只取 1 条结果的搜索,消耗一次 API 调用。
