# Coopanion v0.2.24

**Image search now runs on Pixabay: one key is enough, and it names the photographer**

## Changed

- **Pixabay is the source**: Pexels stopped issuing keys, so Pixabay carries the search (log in at https://pixabay.com/api/docs/, copy your key, put it in `data/home/companion/.env` as `PIXABAY_API_KEY`). When both keys are set Pexels is asked first; if it fails or finds nothing, Pixabay answers.
- **The receipt names the photographer and the source**: each line is `title — direct URL (by photographer · Pixabay)`, ready for a credit line.
- **A Chinese query searches Chinese tags**: a query with Han characters carries `lang=zh`.
- **Safe search is on**: Pixabay requests always carry `safesearch=true`.

## Fixed

- The hand-run check `scripts/check-image-search.ts` called `process.exit()`, which trips a libuv assertion on Node 24; it sets the exit code instead.

## Notes

- The 6,000-character page cap and bubble thumbnails are unchanged.
