# Coopanion v0.2.16

**Upstream v0.2.14 and v0.2.15 brought in: queued replies no longer stop after the first, automatic updates can be turned off, an incomplete install asks to be reinstalled, and the whale's eyes are back where they were**

## Fixed (from upstream)

- **Only the first of several replies**: after the pointer rested on Coo's bubble the pet sometimes believed it never left, so the current line was never sent and replies behind it stayed queued. It follows the real pointer position now.
- **Automatic updates can be switched off** in Habits → General; turning them off stops checks, cancels a download and prevents installation.
- **An incomplete install** no longer restarts Core in a loop: it asks to reinstall to the same folder, keeping settings, keys, prompts and memory.
- **The whale's eyes** are back to the v0.2.13 shape and position; the animation stays.
- **A workspace with thousands of files** no longer hands off forever: deep directories fold into one line, and the handoff stops when it cannot help.
- **Sound no longer drops to one side** when Coo sits against a screen edge.
- Also: the stereo switch, figure packs reading their own files, macOS right-side modifiers, and a source build no longer sharing the installed app's taskbar identity.
- **cortico is at v0.2.10**: a failing World stops alone, and the config API refuses undeclared keys instead of dropping them silently.

## Kept from this repository

- **Web search and page reading**: `web_search` and `web_fetch`, on the DeepSeek key already configured.
- **Updates come from this repository**.
