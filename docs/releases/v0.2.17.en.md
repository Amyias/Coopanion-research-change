# Coopanion v0.2.17

**Upstream v0.2.16 brought in: My World and the extension market share one page, the pet no longer sinks when dragged to a display with a different scale, and a config file with a BOM no longer keeps the app from starting**

## New (from upstream)

- **My World and the extension market on one page**: the two tabs switch inside the page; in the market the Worlds fold into a column of icons on the left. Worlds can be grouped and reordered, a button beside the name opens the extension's details, and a new version is marked there.
- **Market filters**: categories on the left; certified or official inside Recommended; series filters to select; notes such as extra software, a key or local models to exclude, and exclusions are kept. Selected and excluded conditions sit above the cards and clear with one click.
- **New colour scheme Milk Coo**: black body, yellow inside the C, black around the eyes.
- **Figure pack import has no size limit**: above 128 MB the confirmation says the pack is large.

## Fixed (from upstream)

- **A config with a BOM**: config.json and the other text files are read with a UTF-8 BOM or as UTF-16 LE, so Core no longer exits.
- **Dragged to a display with a different scale** the pet is no longer enlarged and left half off-screen.
- **Computer-use confirmation while the pet is hidden** uses a system dialog.
- **A removed extension stayed installed**: installing and removing an extension uses the app's own runtime for the package's build script, with no system Node.js needed.
- **Long figure names on the dressing page** wrap to two lines, with the full name on hover.
- **A just-installed extension showed an English name**; it follows the interface language before a restart too.
- **Speech recognition dropped ordinary sentences**; only the original line of a video's end credits is discarded.
- **The macOS title bar divider** lines up with the expanded sidebar; UI copy covers nine languages and uses two-character verbs.

## Changed

- **cortico is at v0.2.11**: whole text files are read with a UTF-8 BOM or UTF-16 LE; an installed extension's display name follows the interface language.

## Kept from this repository

- **Web search and page reading**: `web_search` and `web_fetch`, on the DeepSeek key already configured.
- **Updates come from this repository**.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.17.exe`
- `latest.yml`: the version file the updater reads; no need to download it.
