# Coopanion v0.2.32

**合并官方新提交:设置窗口的提示统一了,麦克风可以挑设备**

## 从官方并入

- **设置窗口**:扩展市场、World 卸载与待重启、提示词、供应商、配置、存储、用量、首页、装扮、衣服、电脑操作页的报错与状态提示统一;一批样式与交互修复。
- **桌宠语音**:可以选择具体麦克风,所选设备不在时自动回退系统默认;关掉麦克风 AGC(自动增益);共用说话键时保留开头音频;组合键里按下的 Ctrl、Alt 不再计入连按。
- **图片回执**:工具回执后紧跟一批投递时,下一次请求仍带上回执里的图片。
- **README 重写**:中英 README 按 v0.2.17 重写并换了截图。

## 我们这边

- 合并后保留全部自有能力:网页图片清单、必应图片兜底、气泡图片轮播与放大、Node 更新器、非官方声明与 NOTICE。
- **一行安装脚本改指本仓**:之前它向上游要最新 Release,跑完装的是官方 Coopanion。
- README 采用官方新版结构,本仓徽章、个人修改版声明和联网搜索功能说明已回贴;所有仓库链接指向本仓。
