# Coopanion v0.2.31

**网页里的图能直接拿，图库里没有的图用必应补**

## 新增

- **读网页时列出图片**:正文后面附上这一页的图片地址（og:image、普通图片、懒加载属性、srcset 都认），挑一个就能让 Coo 用 `web_fetch_image` 取回来，不用再操控浏览器。
- **必应图片兜底**:Pixabay 没配密钥、被拒或没结果时，改用免密钥的必应图片搜索；回执里会写明来源。

## 改动

- **移除 Pexels**:它已停止签发密钥，代码、设置页、测试与文档一并去掉，图库只剩 Pixabay。
- 新增三个设置项：网页图片清单元数（默认 12）、网页 HTML 上限（默认 2 MB）、必应图片兜底（默认开），都即时生效。

## 说明

- 页面图片清单是**尽力而为**:直连被墙、反爬或需要登录的站点拿不到图片地址（例如维基、知乎、小红书），这类仍然只能走浏览器。
- 搜图会先花一次 Pixabay 请求；必应兜底只在它没答案时才发。
