# Coopanion v0.2.18

**自动更新不再依赖浏览器的网络栈:在这台机器上它终于能查到 Release 了**

## 修复

- **自动更新收不到新版本**:检查更新走的是 Electron(Chromium)的网络栈，某些机器上到 `github.com` 的连接会超时(杀毒软件拦截非浏览器的 TLS 时会这样)，`updater.log` 里只有 `net::ERR_TIMED_OUT`。现在 Windows 上的检查、下载和 sha512 校验改在主进程用 Node 的 https 完成；安装仍然用应用自己的安装包，静默装回程序所在的目录，装完按需重启。
- 设置窗标题栏的版本提示跟着这条路径一起恢复。

## 说明

- 这一版得手动装一次：自动更新还没修好时，它下载不到这一版。装完以后后续更新就走新路径。
- 联网搜索、读网页、电脑操作这些都没变。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.18.exe`
- `latest.yml`:自动更新读的版本信息，不用下载。
