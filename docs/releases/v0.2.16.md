# Coopanion v0.2.16

**跟上官方 v0.2.14、v0.2.15 的修复:连发消息不再只出第一条回复、自动更新可以关闭、安装没装完时提示重装、大肥鱼的眼睛回到原来的位置**

## 修复（来自官方）

- **连发消息只出第一条回复**:鼠标在 Coo 的气泡上停过以后，桌宠有时以为鼠标一直没离开，这句话一直不收，后面排队的回复和提问也出不来。现在按真实的光标位置判断。
- **自动更新开关**:「习惯 → 通用 → 自动更新」默认开启;关闭后停止检查、取消正在进行的下载，已下载的更新也不再安装。
- **安装没装完**:安装或更新中途被打断、程序文件缺失时，不再反复重启 Core，改为提示从下载页重新安装到原来的文件夹，设置、API Key、提示词和记忆都会保留。
- **大肥鱼的眼睛**:两只眼的虹膜形状和位置回到 v0.2.13 的样子，只去掉了贴图里的高光;会动的高光照旧。
- **工作区文件太多时反复交接**:很深的目录在上下文清单里折成一行;仍然降不下来时停止交接，照常运行。
- **Coo 贴着屏幕边时声音只剩一边**:按位置分配声道时，远侧声道最低只压到约 -8 dB 的问题已修。
- **左右声道开关**、**形象包可以读自己目录里的文件**、**macOS 右侧修饰键**、**从源码运行不再共用已安装版的任务栏身份**。
- **cortico 升到 v0.2.10**:运行中某个 World 出错时只停掉这一个;配置接口收到未声明的键时整体拒绝并提示，不再静默丢掉。

## 保留（本仓库自己加的）

- **联网搜索与读网页**:`web_search`、`web_fetch` 都在，密钥沿用已经配好的 DeepSeek key。
- **更新指向本仓库**:版本检查和下载都读 Amyias/Coopanion-research-change。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.16.exe`
- `latest.yml`:自动更新读的版本信息，不用下载。
