# Coopanion v0.2.33

**合并官方 0.2.18:开局引导能退回上一步,电脑操作能按住键和鼠标键**

## 从官方并入

- **开局引导可以退回上一步**:语言页之后的每个问题,气泡左上角都有「上一步」;回到前一个问题时显示当时的回答,可以重新选择。
- **电脑操作能按住**:Coo 可以按住一个键或组合键最多 30 秒,也能按下、松开鼠标键来拖动;一轮结束时仍按着的都会松开。
- **形象包音效的 repeat**:上一次音效没放完又被触发时,可以设为打断重播、等放完再放或叠着放。
- **选择具体的麦克风**:语音输入页的麦克风下拉列出每个输入设备,设备不在时改用系统默认。
- **修复**:语音输入不再开自动增益;共用说话键时句首音频不再丢;Ctrl+复制/粘贴、Alt+Tab 不再被当成连按;截图回执后紧跟事件时截图不再丢;GNOME 上新窗口能拿到焦点;安装或卸载扩展时退出会等它做完(最多 65 秒);设置窗口的报错提示贴在触发它的控件旁边。
- **高级模式**:去掉旧的端点设置面板,端点与报价都在「模型供应商」页编辑。
- **子模块升到 Cortico v0.2.13**:工作区写入按落盘路径校验(拒绝 `.git` 这类点开头的路径),边输出边执行的工具不再被屏障拦下,获取模型列表不要求先填模型。

## 说明

- 我们的版本号继续自己的序列;官方 0.2.18 的说明不覆盖我们已发的同号版本记录。
- 合并后保留全部自有能力:网页图片清单、必应图片兜底、气泡图片轮播与放大、Node 更新器、非官方声明与 NOTICE。
- Windows 自动更新照旧,macOS 与便携版手动下载。
