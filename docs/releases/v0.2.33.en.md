# Coopanion v0.2.33

**Upstream 0.2.18 merged: the introduction steps back, computer use holds keys and mouse buttons**

## Brought in from upstream

- **The introduction steps back**: every question after the language page has a Back button in the bubble's top left; going back shows the earlier answer, which can be changed.
- **Computer use can hold**: Coo can hold a key or chord for up to 30 seconds and press or release mouse buttons to drag; whatever is still held is released when the turn ends.
- **Figure pack sound repeat**: a sound triggered before the previous one finished can restart, wait its turn, or overlap.
- **Pick a specific microphone**: the voice input page lists every input device and falls back to the system default when one is gone.
- **Fixes**: voice input no longer enables automatic gain control; the first sound of a shared talk key is kept; Ctrl+C/V and Alt+Tab no longer count as double presses; a screenshot followed by more events still reaches the model; new windows can take focus on GNOME; quitting during an extension install or uninstall waits for it (up to 65 seconds); settings errors sit beside the control that caused them.
- **Advanced mode**: the old endpoint settings panel is gone; endpoints and pricing are edited on the provider page.
- **Submodule to Cortico v0.2.13**: workspace writes are checked against the path they land on (dot-paths like `.git` refused), streaming tools are no longer held by the barrier, and listing models no longer requires a model name.

## Notes

- The version number follows our own sequence; upstream's 0.2.18 notes do not replace the record of our same-numbered release.
- Every fork addition survives the merge: page picture lists, the Bing fallback, bubble pictures and their lightbox, the Node updater, the not-official notice and NOTICE.
- Windows updates work as before; macOS and the portable build are downloaded by hand.
