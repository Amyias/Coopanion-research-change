# Coopanion v0.2.18

**Automatic updates no longer ride the browser's network stack: on this machine they finally see the release**

## Fixed

- **Updates were never found**: the check ran on Electron's (Chromium's) network stack, and on some machines the connection to `github.com` times out — a security product intercepting TLS for programs that are not browsers does this — leaving only `net::ERR_TIMED_OUT` in `updater.log`. On Windows the check, the download and the sha512 check now run in the main process over Node's https. The install still uses the app's own setup, silently into the directory the program runs from, with a restart when asked.
- The version hint in the settings window's title bar recovers with the same path.

## Notes

- This version has to be installed by hand once: while updates were broken it could not download itself. After that, updates take the new path.
- Web search, page reading and computer use are unchanged.

## Download

- Windows x64 installer: `Coopanion-Setup-0.2.18.exe`
- `latest.yml`: the version file the updater reads; no need to download it.
