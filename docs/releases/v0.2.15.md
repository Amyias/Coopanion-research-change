# Coopanion v0.2.15

**Coo 能读你给的网页了:搜索之外多了一个 `web_fetch`,拿回标题和 Markdown 正文**

## 新功能

- **读网页**:给 Coo 一个链接，或者它判断某条搜索结果需要看全文时，它用 `web_fetch` 把那一页读下来，拿到标题和 Markdown 正文。长页面截到前 12000 字符，回执里写明全文一共多少字符。
- **不用新配置**:用的就是「联网搜索」已经配好的那把 DeepSeek key。服务端拒绝时(403 安全策略、404 取不到可用内容、402 余额不足)原样转述服务给的理由，不猜。

## 说明

- 只有 Windows x64 安装版，自动更新读本仓库的 Release。
- 安装包没有数字签名，首次手动运行时 Windows 可能拦截。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.15.exe`
- `latest.yml`:自动更新读的版本信息，不用下载。
