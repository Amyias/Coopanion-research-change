# Coopanion v0.2.34

**合并官方修复:服务不收带图请求时,自动去掉图片重发一次**

## 从官方并入

- **图片回退**:带图请求被服务端拒绝(400 / 413 / 422,且不是上下文超限)时,去掉这次请求里的图片重发一次;重发成功才记住这个端点不收图,正文里补一行 `imageLeftOut`。之前这种情况会让那一批直接失败,而且那张图会被一直当成"没发过",之后每批请求都带着它、次次失败。
- 重发也失败时,错误带上两次尝试,图片不记下,Core 照常处理。
- 新测试用本地假服务覆盖四种协议:第一次 400 后第二次成功、之后请求不再带图;重发也失败时下一次请求照常带图。

## 说明

- 官方这个提交还没有发版,版本号继续用我们自己的序列。
- 其余能力不变:网页图片清单、必应兜底、气泡图片、Node 更新器、非官方声明与 NOTICE。
- Windows 自动更新照旧,macOS 与便携版手动下载。
