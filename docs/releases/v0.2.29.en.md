# Coopanion v0.2.29

**The package carries its license and notice**

## Fixed

- Earlier packages carried the program alone, without `LICENSE` or `NOTICE`. The packing step now copies both into the app directory (under `resources/app` after installation), so a distributed binary carries the AGPL text and the statement that this is a personal modified version.
- The licensing section of the development notes now names that packing step.

## Notes

- Behaviour is unchanged; updates work as before.
