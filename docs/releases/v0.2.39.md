# Coopanion v0.2.39

**修复 Windows 自动更新在加入 Arm64 安装包后选错安装包**

## 修复

- **Windows 自动更新会下载 Arm64 安装包**:0.2.38 起 Release 里同时有 x64 与 Arm64 的安装包,更新器按资产列表顺序挑第一个 `.exe`,而 `Coopanion-Setup-版本号-arm64.exe` 排在前面,x64 电脑会下到 Arm64 安装包(校验也对错了通道文件)。现在按运行时的处理器挑选安装包:x64 取 `Coopanion-Setup-版本号.exe`,Arm64 取 `…-arm64.exe`。
- **校验用同一处理器的通道文件**:没有 sha256 的旧 API 答复下,x64 读 `latest.yml`,Arm64 读 `latest-arm64.yml`,不再用 x64 的摘要去校验 Arm64 安装包。
- 新增两个测试:双架构资产下按处理器选安装包、无摘要时按处理器读通道文件。

## 说明

- 只改了 `app/node-updater.cjs` 与它的测试;0.2.38 已装的应用需要手动装一次 0.2.39(自动更新本身在 0.2.38 上会选错),之后恢复正常。
