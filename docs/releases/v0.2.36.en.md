# Coopanion v0.2.36

**Two console layout fixes from upstream**

## Brought in from upstream

- **The level column in the run log lines up with its row**: the `font:` shorthand reset the line height to normal and the level sat 3–4 px above the other words; the family, size and weight are now set separately and the row's line height is inherited.
- **An empty read-failure bar no longer draws a top border on the first card**: the pet, voice input and prompt template pages put a read-failure bar first; it is hidden when empty, but the card after it still counted as "first" and kept its top border and padding. A card that follows an empty bar now counts as first.

## Notes

- Only `console/styles.css` changed; no new features and no interface changes.
- The fork's own changes, the not-official notice and NOTICE are unaffected.
