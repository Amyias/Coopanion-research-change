# Coopanion v0.2.40

**Upstream 0.2.24 and 0.2.25 merged: Coo can fade, a held key lets it be clicked while click-through is on, balanced bubble lines, usage by World; the handoff fix**

## Brought in from upstream (36 commits)

- **Coo can fade**: Habits → Display → Opacity, 0–95%, or add Opacity to the hover buttons and drag its slider over Coo's head; only the figure fades, bubbles, buttons and the menu do not. On Windows the full-screen row gains a Fade value (40% by default).
- **Hold a key to click Coo while click-through is on**: a new Pause Click-through key (right Ctrl by default); hold it and Coo takes clicks as usual, release and clicks pass through again. The hover buttons can carry Click-through and Computer Use switches.
- **Motion levels**: low, medium, high or follow the system (default).
- **Bubbles**: wrapped lines are narrowed to equal widths, the close button moves outside the bubble, typed text fills the whole input, an automatic input bubble fades 0.5 s after Coo's reply finishes, and the tail's line matches the border. The Habits page groups bubble settings with a playable example.
- **Recording-only delivery no longer waits for transcription**, and the recognizer can be stopped on its own and stays stopped.
- **A toolbar for a World's environment prompt page**; leaving with unsaved edits uses an in-app dialog; **usage by World** in the usage page.
- Fixes: Coo floating after a display-scale change, a DeepSeek peak/off-peak instance turned into the Coo Pet Provider on restart (the 0.1.2 endpoint migration is gone), colour scheme reset on restart, input over the limit truncated, the settings window not reloading after a same-port Core restart, a frame flashing when dragging Coo across displays, the guide's line held by the pointer, asymmetric figure packs not reaching the screen edge, and more.
- **0.2.25**: fixes "no handoff after the first one" on 0.2.24; a handoff that cannot get back under the threshold is retried once, then stops with the settings to change named in `logs\core.log`; a crashing process leaves a `.dmp`; the context estimate before a request includes the tool list; Cortico v0.2.19.

## What this fork keeps

- The bundled WebSearch and web-fetch Worlds (web search, page picture lists, Bing fallback) and the "websearch on for new deployments, switched on when upgrading" migration; only upstream's 0.1.2 endpoint migration is dropped.
- Windows updates keep the Node transport (including 0.2.39's per-processor installer and channel choice) while taking upstream's new installer: silent install, payload verification and rollback.
- On the pet page upstream's head slider replaces the size slider; the fork's bubble carousel, click-to-enlarge and lightbox fit the new bubble structure, and click-to-skip still excludes pictures.
- The READMEs and DEVELOPMENT take upstream's install instructions while keeping this fork's repository links, badges, not-official notice and Node updater notes.
- The version number follows our own sequence.
