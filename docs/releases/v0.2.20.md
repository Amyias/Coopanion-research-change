# Coopanion v0.2.20

**自动更新能装上去了:上一版退出时传的安装参数会让安装包直接中止**

## 修复

- **下载完却装不上**:0.2.19 退出时用 `--updated /S --force-run` 调安装包，这个安装包收到 `--updated` 会以退出码 2 中止(手动跑也一样)。现在改成 `/S --force-run`：静默装回程序所在目录，装完自动把应用启动起来。
- 这一版装完以后，后续更新才会自己走完整条路(检查 → 下载 → 校验 → 退出时安装 → 重启)。

## 说明

- 0.2.19 装不上自己的更新，所以这一版需要手动装一次。
- 联网搜索、读网页、电脑操作不变。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.20.exe`
- `latest.yml`:自动更新读的版本信息，不用下载。
