# Coopanion v0.2.36

**合并官方控制台的两个排版修复**

## 从官方并入

- **运行日志的级别一列对齐了**:原来用 `font:` 简写把行高重置成 normal,级别比同行其它字偏上 3～4px;现在分别设字体族、字号、加粗,行高继承表格行。
- **空着的读取失败提示条不再撑出第一张卡的上边线**:桌宠、语音输入、提示词模板三页在第一个位置放提示条,空着时不显示,但它后面的那张卡仍然算「第一个」,去不掉上边线与上内边距。现在空提示条后面的卡也按第一张处理。

## 说明

- 只动了 `console/styles.css` 一个文件,没有新功能,也没有接口变化。
- 本仓的对接改动、非官方声明与 NOTICE 不受影响。
