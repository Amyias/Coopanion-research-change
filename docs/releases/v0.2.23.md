# Coopanion v0.2.23

**要图不用开浏览器了**

## 新增

- **搜图**:新工具 `web_search_images`。说“给我找张柯基的图”，它去 Pexels 或 Pixabay 搜，拿到图片直链后用 `web_fetch_image` 取回来，作为附件放进对话。
- 需要任意一个免费 key:写进 `data/home/companion/.env` 的 `PEXELS_API_KEY`、`PIXABAY_API_KEY`(Pexels 优先),重启应用生效。

## 修复

- **抓网页的回执超长**:默认截断 12,000 字符超过了 Core 的 8,000 上限，多出来的被白白丢弃。默认改成 6,000。

## 说明

- 免 key 的图源这条路走不通:维基共享资源和 Openverse 在这条网络连不上，Bing 返回广告图、百度返回反爬页，所以搜图用需要注册的免费 key。
