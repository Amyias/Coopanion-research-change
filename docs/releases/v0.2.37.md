# Coopanion v0.2.37

**合并官方 0.2.20 与 0.2.21:桌宠大小直接调、点气泡跳过、右键菜单只放悬停按钮、不盖任务栏、不进截图**

## 合并的官方改动(24 个提交)

- **调桌宠大小**:装扮页的形象下面与悬停按钮里都有「大小」,拖动时 Coo 跟着变;每个形象、每个收藏各记自己的大小。
- **点一下台词气泡跳过整句**:气泡淡出、声音停下,后面排队的台词继续;提问和确认气泡仍要回答。
- **确认时提醒音响一声**(习惯页 → 音效 → 提醒,默认开),**等待时状态气泡显示还剩几秒**。
- **悬停按钮与右键菜单的悬浮说明**(停半秒显示名称与当前状态)、菜单/按钮/收藏表盘的进出动画。
- **右键菜单只放固定的悬停按钮**(与鼠标悬停出现的是同一组,最多 6 个),旧安装在更新后会被告知一次;开局引导里可以多选悬停按钮。
- **习惯页的分区跳转栏**。
- **Coo 能取一张自己此刻的屏幕截图**(只有身体,不含气泡和桌面);**答应的事记进 todo.md**,重复文件当场合并,每批事件前那行带日期。
- **Windows「显示在任务栏上」开关**(默认开)与**「不出现在截图和录屏里」开关**(默认关)。
- **Gemini 端点接收音频、视频、PDF 附件**(合计 ≤18 MiB);Claude 端点跳过不支持的附件。
- 修复:交接后重复回答、ChatGPT 登录后 400、带图请求被拒卡住、收藏读取失败误写、Wayland 退出、
  扩展事件时区差 8 小时、Minecraft 断开后又连、用量账本卡顿、形象包运行失败原因、引导每步停顿等。
- 子模块 Cortico 升到 v0.2.16:音视频附件按类型落盘、图片回落(400/413)沉到 cortico 层。

## 本仓处理

- 气泡图片轮播、点图放大、`/say-image`、`/api/looks`、网页图片清单、必应兜底、Node 更新器、非官方声明与 NOTICE 全部保留。
- 与上游交互冲突处:**点气泡里的图片是放大图片,不是跳过整句**;跳过监听排除 `.b-pics`,图片放大后再点气泡才跳过。
- 桌宠排队逻辑改用上游按 id 前移的 `sayEnds`;图片 hold 沿用我们的 `imageHoldSeconds`,旧的 `pointedAt()` 换成上游的 `held`。
- 版本号继续我们自己的序列。
