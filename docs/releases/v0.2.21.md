# Coopanion v0.2.21

**自动更新的检查不再先连 github.com:一次 API 调用 0.1–0.9 秒，失败会写明原因**

## 修复

- **检查更新先下载 latest.yml**:这一步走的是 `github.com`，在有些机器上会超时，导致检查卡住或静默失败。现在版本、文件大小和 sha256 都取自发布接口的回答，检查只需一次 API 请求，下载真正开始前不再访问 `github.com`；遇到没有 digest 的旧回答仍然回退读 `latest.yml`。
- **每个请求都有硬超时**；检查失败、下载失败都会写进 `updater.log`，不再无声无息。
- 安装参数沿用上一版修好的 `/S --force-run`。

## 说明

- 这一版仍需手动装一次；装完之后，后续更新会自己走完检查 → 下载 → 校验 → 退出时安装 → 重启。
- 联网搜索、读网页、电脑操作不变。

## 下载

- Windows x64 安装版:`Coopanion-Setup-0.2.21.exe`
- `latest.yml`:自动更新读的版本信息，不用下载。
