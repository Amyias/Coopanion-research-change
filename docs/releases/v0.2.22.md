# Coopanion v0.2.22

**Coo 能把网图取回来了**

## 新增

- **取回一张网图**:新工具 `web_fetch_image`。给它一个图片链接，它把图下载下来作为附件交给你——在「对话」页直接看得到，它自己也能看图里的内容。图片类型按文件头判断，单张上限 8 MB。
- **不会去碰你的本机**:链接指向 `localhost`、本机地址或局域网（10/172.16/192.168 等）时直接拒绝，也不发请求，避免被诱导去扫你的设备。
- 取回的图还能用 `pet_say` 发出来，和别的附件一样留在对话里。
